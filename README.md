# ADSAI PRO

SaaS de gestión de Google Ads con IA para el mercado hispanohablante.

## Stack

- **Frontend:** React 18 + Vite + Tailwind CSS + Recharts
- **Backend:** Node.js 20 + Express
- **DB:** Supabase (PostgreSQL) + Redis
- **IA:** Claude Sonnet 4.6 + Haiku 4.5 (Anthropic API)
- **Pagos:** Stripe
- **Infra:** Vercel (frontend) + Railway (backend)

## Estructura

```
adsai-pro/
├── frontend/          → React + Vite
├── backend/           → Node.js + Express
└── docs/              → Documentación y brief
```

## Inicio rápido

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
npm install
npm run dev
```
